# VK-бот «День карьеры» — исправленный пакет для Bothost

## Исправление ошибки `SyntaxError: invalid decimal literal`

В исходном файле `main.py` на хостинг попала Base64-строка с содержимым программы. Python не умеет выполнять Base64 как обычный исходный код. В этом архиве `main.py` уже декодирован и начинается с `# -*- coding: utf-8 -*-`.

## Установка

1. Загрузите содержимое архива на Bothost либо замените на сервере именно файл `main.py` этим файлом.
2. В качестве главного файла запуска выберите `main.py`.
3. Установите зависимости из `requirements.txt` (`openpyxl==3.1.5`).
4. Укажите переменные окружения из `.env.example` в панели Bothost. Не загружайте реальные токены и пароли в этот файл.
5. Установите `DATABASE_PATH=/app/data/career_bot_vk.db` и не удаляйте существующую SQLite-базу.
6. Перезапустите бота и проверьте логи.

## Важно

Используйте обычный текстовый Python-файл `main.py`, а не Base64. Его первая строка должна быть `# -*- coding: utf-8 -*-`, а не `IyAtKi0...`.
