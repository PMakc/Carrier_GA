# VK-бот «День карьеры» — Bothost

Подготовленный пакет для запуска через VK Long Poll на Bothost.

## Что изменено

- Секреты больше не хранятся в исходном коде: токен VK, ID администраторов и пароль организатора берутся из переменных окружения.
- Исправлена проверка нескольких администраторов.
- Станции хранятся в SQLite, а не в словаре Python. Из админского меню можно добавлять, редактировать и отключать станции.
- Списки станций для редактирования и отключения разбиты на страницы по 16 пунктов: клавиатура не превышает лимит VK в 10 строк.
- Стартовые коды заменены на тематические геолого-промышленные слова с непоследовательными пятизначными суффиксами. Они не содержат названий предприятий или номеров станций; при обновлении v2 коды меняются на месте, ID и история посещений сохраняются.
- При первом запуске человек выбирает режим «Участник» или «Организатор». Для организатора требуется специальный код `ORGANIZER_PASSWORD`. После успешной проверки доступ организатора сохраняется; между режимами можно переключаться без повторного ввода кода.
- Количество станций динамическое: прогресс, завершение маршрута, список победителей и розыгрыш больше не привязаны к числу 13.
- В разделе «Мой прогресс» показываются все активные станции маршрута: ✅ пройденные с датой/временем отметки и ⬜ ещё не пройденные. Счётчик и список строятся по одному набору активных станций; отключённые станции не отображаются.
- Отключение станции не удаляет старые записи о посещениях. Она исключается из текущего маршрута.
- Администратор получает Excel-файл через VK. В книге четыре листа: «Сводка», «Участники», «Посещения», «Станции».
- Рулетка обновляет одно сообщение VK, показывает промежуточные результаты и фиксирует итогового победителя.
- Победители не повторяются в следующих запусках розыгрыша. Администратор может сбросить историю розыгрыша.
- База использует WAL, тайм-аут блокировки и хранится в `/app/data` на Bothost.
- Улучшены сообщения, меню, подсказки, прогресс-бар и обработка ошибок Long Poll.

## ВАЖНО: безопасность перед запуском

В загруженном исходном `BOT.py` был указан действующий на вид токен VK и пароль организатора. Считайте их скомпрометированными:

1. Отзовите старый ключ доступа сообщества VK и создайте новый с правом работы с сообщениями.
2. Задайте новый пароль организатора. Не используйте старое значение `org#2025`.
3. Не публикуйте токен, пароль или файл с ними в Git-репозитории и не отправляйте их в переписке.

В этой версии секретов из исходного файла нет.

## 1. Настройки сообщества VK

В настройках сообщества:

1. Разрешите сообщения сообщества.
2. Создайте ключ доступа сообщества с правом отправки и получения сообщений.
3. Включите Long Poll API для сообщества.
4. Включите событие `message_new`.

Бот работает в личных сообщениях сообщества. Сообщения из бесед игнорируются.

## 2. Загрузка на Bothost

1. Создайте VK-бота в разделе VK на Bothost.
2. Загрузите архив `bothost_vk_bot.zip` или подключите Git-репозиторий с его содержимым.
3. Укажите главный файл запуска: `main.py`.
4. Убедитесь, что Bothost использует Python и устанавливает зависимости из `requirements.txt`.
5. В разделе переменных окружения добавьте значения из следующего блока.
6. Запустите деплой и проверьте «Логи работы».

### Переменные окружения

| Имя | Значение |
|---|---|
| `VK_TOKEN` | **Новый** ключ доступа сообщества VK |
| `VK_GROUP_ID` | `241674433` |
| `ADMIN_IDS` | `381579176,585232246` |
| `ORGANIZER_PASSWORD` | Новый длинный пароль организатора, придумайте самостоятельно |
| `DATABASE_PATH` | `/app/data/career_bot_vk.db` |
| `MIN_TIME_BETWEEN_STATIONS` | `180` |
| `ANTI_SPAM_COOLDOWN` | `2` |
| `VK_API_VERSION` | `5.199` |
| `LOG_LEVEL` | `INFO` |

Не вставляйте токен или пароль в `main.py`, `README.md` или Git. Если в панели вашего тарифа нет раздела переменных окружения, уточните у Bothost доступный способ безопасной передачи секретов или тариф с поддержкой env-переменных.

## 3. Сохранение уже имеющихся данных

Если прежний бот уже работал и в его папке есть `career_bot_vk.db` с участниками и посещениями:

1. Скопируйте этот файл до остановки старого бота.
2. До первого запуска новой версии загрузите его в папку `/app/data` на Bothost.
3. Установите `DATABASE_PATH=/app/data/career_bot_vk.db`.

Новая версия автоматически обновляет коды 14 стартовых станций с предыдущего набора на тематические, не меняя ID и историю посещений. Если в базе находятся прежние встроенные станции предыдущей версии, они архивируются (история посещений остаётся в базе), а новые станции добавляются с новыми ID. Посещения старых станций не засчитываются в новом маршруте. Пользовательские станции, добавленные администратором, сохраняются активными. Если используется база из первоначального BOT.py без таблицы stations, новые ID назначаются после максимального старого station_id, чтобы прежние отметки не засчитались ошибочно.

Не запускайте одновременно старую и новую версии с одной базой данных.

## 5. Как пользоваться новыми функциями

### Организатор и администратор

Откройте диалог с сообществом и отправьте `/start`. Пользователь, который ввёл правильный `ORGANIZER_PASSWORD`, получает панель организатора с рабочими функциями мероприятия: управлением станциями, Excel-отчётом, статистикой и розыгрышем. Эти права сохраняются в SQLite и не требуют повторного ввода пароля.

Пользователи, перечисленные в `ADMIN_IDS`, автоматически получают расширенную панель администратора и могут выбрать режим организатора без ввода пароля. Помимо функций организатора, им доступен полный **«Сбросить День карьеры»**. Эта операция намеренно не показывается обычным организаторам.

**Управление станциями** →
- «Добавить станцию»: отправьте `Название станции | КОДОВОЕ_СЛОВО`, например `Новое предприятие | МЕДЬ2026`.
- «Редактировать станцию»: выберите её по ID, затем отправьте `Новое название | НОВЫЙ_КОД2027`. Название и код изменятся; журнал прежних посещений будет отображаться с новым названием.
- «Удалить станцию»: выберите её из списка. Она отключается от маршрута и код перестаёт приниматься. История посещений остаётся в базе для сохранения отчётности. Последнюю активную станцию отключить нельзя.
- Списки выбора разбиты на страницы по 16 станций; в одной клавиатуре используется не более 10 строк.

ID новой станции показывается после добавления. Для ручной отметки используйте `/visit_ID` или `/visit_ID VK_ID`.

**Excel-отчёт** отправляет файл `.xlsx` с четырьмя листами:
- «Сводка» — основные показатели;
- «Участники» — ФИО, VK ID, прогресс и отметки по станциям;
- «Посещения» — подробный журнал посещений с датой и временем;
- «Станции» — число отметок и уникальных участников по каждой активной станции.

**Розыгрыш** выбирает участника, завершившего все текущие активные станции. Один участник не может выиграть повторно, пока организатор или администратор не нажмёт «Сбросить розыгрыш» и не подтвердит действие.

### Первый вход и переключение ролей

При первом `/start` бот предлагает выбрать «Участник» или «Организатор».

- При выборе «Участник» пользователь указывает ФИО и получает меню участника.
- При выборе «Организатор» пользователь вводит специальный код из `ORGANIZER_PASSWORD`.
- После правильного кода доступ организатора сохраняется в SQLite. В меню обеих ролей доступна кнопка «Сменить роль»; при возвращении в режим организатора код повторно вводить не нужно.
- Регистрация участника и ФИО сохраняются при переключениях.

Организатор может переключиться в режим участника, вводить коды станций и накапливать собственный прогресс. Чтобы снова увидеть инструменты управления станциями, Excel и розыгрыш, нужно вернуться в режим организатора. Полный сброс Дня карьеры остаётся доступен только пользователям из `ADMIN_IDS`.

### Участник

Участник регистрируется по ФИО, получает код на стенде предприятия и отправляет его боту. Кнопка «Мой прогресс» показывает динамический прогресс по активным станциям.

## 6. Локальный запуск для проверки

Требуется Python 3.10+.

Установите зависимости:

```bash
pip install -r requirements.txt
```

Задайте переменные окружения в терминале, затем выполните:

```bash
python main.py
```

В Windows PowerShell переменные можно задать так:

```powershell
$env:VK_TOKEN = "НОВЫЙ_ТОКЕН"
$env:VK_GROUP_ID = "241674433"
$env:ADMIN_IDS = "381579176,585232246"
$env:ORGANIZER_PASSWORD = "ВАШ_НОВЫЙ_ПАРОЛЬ"
$env:DATABASE_PATH = ".\career_bot_vk.db"
python main.py
```

## 7. Состав архива

- `main.py` — код бота;
- `requirements.txt` — зависимости;
- `.env.example` — пример списка переменных, без токена и пароля;
- `.gitignore` — исключение базы и секретных файлов из Git.

Пакет не содержит ваши реальные токены, пароль или локальную SQLite-базу.


## Если Excel не отправляется

Для выгрузки нужны два права ключа сообщества VK: **«Сообщения сообщества»** и **«Документы сообщества»**. После изменения прав создайте новый ключ и обновите `VK_TOKEN` в переменных Bothost, затем перезапустите бота. Также должны быть включены сообщения сообщества и доступен личный диалог с ботом.

Зависимость `openpyxl==3.1.5` уже указана в `requirements.txt`; Bothost должен устанавливать зависимости из этого файла. Включать Excel или Python-пакет в настройках VK не нужно.

Если ошибка повторяется, откройте логи Bothost сразу после нажатия «Excel-отчёт». Ищите сообщения `VK API docs.getMessagesUploadServer`, `VK API docs.save`, `Не удалось загрузить Excel в VK` или `Excel was uploaded but VK failed to send`. Код ошибки VK поможет определить, какое именно действие отклонено.

В этой версии обработан формат ответа `docs.save` VK API (`{type: "doc", doc: {...}}`), а успешность отправки файла теперь проверяется отдельно.

## Полный сброс Дня карьеры

В панели администратора добавлена кнопка **«Сбросить День карьеры»**. После нажатия бот показывает отдельное предупреждение и требует подтверждения.

Сброс удаляет:
- регистрации участников и сохранённые данные организаторов;
- все отметки о посещении станций;
- временные ограничения между отметками;
- счётчики антиспама;
- историю розыгрыша.

Сохраняются список станций, их названия и кодовые слова, настройки приложения, а также доступ администраторов, указанных в `ADMIN_IDS`. Организаторам после сброса потребуется снова пройти вход по `ORGANIZER_PASSWORD`. Администраторы повторно вводить пароль не должны.

**Внимание:** удалённые игровые данные восстановить кнопкой нельзя. Перед нажатием сделайте копию SQLite-базы, если результаты мероприятия могут ещё понадобиться.
